## 4. 핵심 질문 답변 (A3 ~ A8)

### A3 · 대비도(Contrast)의 붕괴 양상과 1.0 및 0.5 이하로 떨어지는 임계 차원
- $d = 2$에서는 가장 먼 쌍이 가장 가까운 쌍보다 약 **489배(`contrast = 488.582`)** 더 멀어 "가깝다"와 "멀다"의 구분이 극명하지만, 차원이 커지자 대비도가 기하급수적으로 붕괴합니다.
- **$\text{contrast} < 1.0$이 되는 차원**: **$d \approx 50$** (`contrast = 0.982`, 즉 $\max - \min < \min \iff \max < 2\min$이 되어 가장 먼 점조차 가장 가까운 점의 2배 거리 안에 들어옴).
- **$\text{contrast} < 0.5$가 되는 차원**: **$d \approx 110 \sim 120$** ($d = 100$에서 `0.545`, $d = 200$에서 `0.372`로 하락하며, $d = 1,000$에서는 `0.153`까지 수축해 모든 점 쌍의 거리가 평균 주변 $\pm 7\%$ 대역 안에 밀집됨).

### A4 · 평균 거리(`mean`)의 차원 증가 법칙 검증 ($\sqrt{d}$ 비례성)
- 평균 거리는 $d$에 선형(Linear)으로 비례하지 않고 **$\sqrt{d}$ (구체적으로 $\sqrt{d / 6} \approx 0.4082\sqrt{d}$)에 정확히 비례**하여 증가합니다.
- **이론적 이유와 실측 대조**: $[0, 1]$에서 독립적으로 뽑은 두 균등 확률변수 $X_k, Y_k$에 대해 $\mathbb{E}[(X_k - Y_k)^2] = \int_0^1 \int_0^1 (x-y)^2 dx dy = \frac{1}{6}$이므로, $d$차원 제곱거리 합 $\sum_{k=1}^d (X_k - Y_k)^2$의 기댓값은 $\frac{d}{6}$이고 대수의 법칙에 의해 평균 유클리드 거리는 $\sqrt{d/6}$로 수렴합니다.
- 실제 측정값도 $d = 20$에서 `1.815` (이론값 $\sqrt{20/6} = 1.826$), $d = 200$에서 `5.776` (이론값 $\sqrt{200/6} = 5.774$), $d = 1000$에서 `12.909` (이론값 $\sqrt{1000/6} = 12.910$)로 소수점 셋째 자리까지 $\sqrt{d/6}$ 공식과 완벽히 일치합니다.

### A5 · 상대 표준편차(`rel.sd`)의 감소와 A3(`contrast`) vs A5(`rel.sd`) 비교
- 평균 거리는 $\mathcal{O}(\sqrt{d})$로 커지는 반면, 유클리드 거리의 절대 표준편차(`stdev`)는 중심극한정리(Delta method)에 의해 차원과 무관한 상수($\approx \sqrt{\frac{7}{180}} / (2\sqrt{1/6}) \approx 0.2415$)로 수렴하므로, **상대 표준편차($\text{rel.sd} = \text{stdev}/\text{mean}$)는 $\mathcal{O}(1/\sqrt{d})$ 비율(`0.476` $\to$ `0.193` $\to$ `0.083` $\to$ `0.019`)로 감소**합니다.
- **어느 지표가 "거리가 의미를 잃음"을 더 잘 포착하는가?**:
  - **분포의 본질적 수축을 측정하는 데는 A5(`relative_stdev`)가 더 강건(Robust)하고 근본적인 지표**입니다. `contrast = (max - min) / min`은 표본 내 단 두 개의 극단값(`min`, `max`)에만 의존하므로 우연히 아주 가까운 한 쌍이 뽑히거나 표본 크기가 달라지면 요동치지만, `relative_stdev`는 전체 거리 분포가 평균 주변으로 얼마나 좁게 집중(Concentration of Measure)되는지를 노이즈 없이 안정적으로 보여줍니다. 반면 k-NN이나 최근접 탐색 알고리즘의 최악 조건 분석에서는 양 끝단의 차이를 직접 보여주는 `contrast`가 직관적입니다.

### A6 · 점 개수($n$) 변화가 대비도(Contrast)에 미치는 영향
- $d = 50$으로 고정하고 점 개수 $n$을 `200`, `1,000`, `5,000`으로 변화시켰을 때, `relative_stdev`는 `0.082 -> 0.083 -> 0.084`로 $n$과 무관하게 일정했으며, `contrast` 역시 `20,000`개 무작위 쌍 샘플링 하에서는 **`0.88 ~ 0.98` 범위**에 머물렀습니다.
- 만약 전체 $\binom{n}{2}$개 모든 쌍에 대해 전수 최솟값/최댓값을 구한다면 $n$이 커질수록 더 극단적인 꼬리(Tail)가 관측되어 `contrast`가 $\mathcal{O}(\sqrt{\ln n / d})$ 수준으로 아주 느리게 증가하지만, 차원 $d$는 분모에서 선형으로 작용하는 반면 데이터 개수 $n$은 로그($\ln n$)로만 작용합니다. 즉, **차원이 조금만 커져도 이를 상쇄하려면 데이터 개수 $n$을 기하급수적($e^{\mathcal{O}(d)}$)으로 늘려야 하므로 데이터 양을 늘리는 것만으로는 차원의 저주를 피할 수 없습니다**.

### A8 · 3주차 Jaccard 유사도 기반 LSH(MinHash)도 차원의 저주에 위협받는가?
- **위협받지 않습니다 (No).** 그 이유는 두 가지입니다:
  1. **고차원 공간의 밀집 균등 점(Dense Uniform Cube)이 아니라 극도로 희소한 집합(Sparse Shingle Set)이기 때문**: 차원의 저주(거리 집중 현상)는 모든 $d$개 좌표가 독립적인 노이즈를 동등하게 기여할 때 발생합니다. 반면 문서의 $k$-shingle 집합은 전체 어휘 차원 $D$가 수백만 개라도 한 문서에 등장하는 원소 수는 수백 개뿐이며, Jaccard 유사도 $J(A, B) = \frac{|A \cap B|}{|A \cup B|}$는 **두 문서 모두에 등장하지 않는 대다수의 빈 차원(0-0 매칭)을 아예 계산에서 무시**합니다.
  2. **MinHash의 충돌 확률은 차원 $D$가 아니라 오직 $J(A, B)$ 자체에만 의존**: MinHash에서 $\Pr[h(A) = h(B)] = J(A, B)$라는 등식은 전체 유니버스(차원) 크기 $D$와 완전히 무관하게 성립하므로, 어휘 사전 크기가 수억 개로 늘어나도 비슷한 문서 쌍의 Jaccard 유사도와 LSH 검출 능력은 전혀 희석되지 않습니다.
